## 🚀 Selected Projects

### 🛡️ History-Aware RL Defender for LLM Jailbreaks

`Python` `PyTorch` `PPO` `LLM Evaluation`

Reframed multi-turn jailbreak defense as a sequential decision-making problem and trained a PPO policy to choose between `ALLOW`, `WARN`, and `BLOCK` based on conversation history.

- Reduced held-out harmful attack success rate from **100% to 10%**
- Evaluated against no-defense and always-block baselines
- Used history-aware state representations and counterfactual rewards
